# Jason Lennard

Academic website for Jason Lennard, LSE Economic History.

## Publishing

Enable GitHub Pages from the main branch, root folder. The .nojekyll file allows the HTML pages to be served directly.

## Updating the CV

The CV button on About opens the shared Dropbox file Admin/CV/CV_JL.pdf. Replace that file in place to retain the existing link.

## Pages

About, Research, Teaching, Media, Links and Contact.
